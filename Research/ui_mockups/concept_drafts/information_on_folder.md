This folder contains UI Mockups for the Electronic Health Record. 
These mockups have been digitally hand-drawn and/or designed using Figma.


**Breakdown of Folders:**
  - The **Figma Testing** folder is for mockups that were from testing the features of Figma and not fully designed or working versions of the EHR.
  - The **Sketched Mockups** folder is for all mockups designed, regardless if approved or not for building. These have been digitally hand-drawn.


**EHR Features in Mockups:**
  - Sign-In System for Walk-In + Scheduled Patients
  - Appointment Scheduler
  - Patient Record Lookup
  - Examinations
