This folder contains UI Mockups for the Electronic Health Record. 
These mockups have been created with HTML/CSS.


**Breakdown of Folders:**
  - The **Code** folder is for all code (HTML/CSS) for the mockup.
  - The **Approved** folder is for mockups that were approved to be used for the UI to be built.


**EHR Features in Mockups:**
  - Sign-In System for Walk-In + Scheduled Patients
  - Appointment Scheduler
  - Patient Record Lookup
  - Examinations
